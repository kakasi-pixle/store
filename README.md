# AquaScience | العلوم المتكاملة

موقع تعليمي عربي/إنجليزي للصف الأول الثانوي – الترم الأول. يعمل كواجهة Static بدون تسجيل دخول أو قاعدة بيانات أو تثبيت مكتبات.

## تشغيل الموقع محليًا

1. افتح Terminal داخل هذا المجلد.
2. شغّل:

   ```bash
   python3 -m http.server 8080
   ```

3. افتح `http://localhost:8080`.

يمكن أيضًا فتح `index.html` مباشرة في المتصفح، لكن تشغيل خادم محلي أفضل.

## النشر على Vercel

1. ارفع محتويات المجلد إلى مستودع GitHub.
2. من Vercel اختر **Add New → Project** ثم استورد المستودع.
3. اختر **Other** كإطار العمل (Framework Preset).
4. اترك Build Command وInstall Command فارغين.
5. اجعل Output Directory هو `.` ثم اضغط **Deploy**.

الموقع Static بالكامل، لذلك لا يحتاج إلى Backend أو Environment Variables.

## ملفات المشروع

- `index.html`: بنية الصفحات وعناصر الواجهة.
- `style.css`: التصميم المتجاوب والحركات والثيمات.
- `lessons.js`: بيانات الدروس والشرح والأسئلة والقاموس.
- `experiments.js`: محاكيات المعمل والأنشطة المنزلية.
- `app.js`: التفاعلات والتنقل والاختبارات وحفظ التقدم.
- `vercel.json`: إعدادات النشر.

## ما يتضمنه الموقع

14 درسًا موزعة على وحدتي الأنظمة البيئية المائية والغلاف الجوي، شروحات عربية بالمصطلحات الإنجليزية، أسئلة اختيار من متعدد، قاموس مصطلحات، خريطة المنهج، 10 محاكيات تفاعلية، و8 أنشطة منزلية آمنة. يحتفظ المتصفح بالتقدم والنتائج محليًا باستخدام `localStorage` على نفس الجهاز والمتصفح.

## ملاحظات علمية وحقوق النشر

المحتوى مكتوب بصياغة تعليمية أصلية اعتمادًا على عناوين المنهج والملخص الذي أرسله المستخدم، وليس نقلًا حرفيًا من كتاب المعاصر أو كتاب الوزارة. راجع الكتاب المدرسي المعتمد عند الحاجة إلى نص أو ترتيب صفحة بعينها. الأنشطة المنزلية للتعلم والملاحظة فقط، ويجب تنفيذها بإشراف شخص بالغ عند الحاجة وعدم خلط المنظفات أو تسخين مواد مجهولة.
