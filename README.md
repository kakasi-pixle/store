# AquaScience | مختبر العلوم المتكاملة

موقع تعليمي تفاعلي باللغة العربية مع المصطلحات العلمية بالإنجليزية، مخصص لمراجعة منهج العلوم المتكاملة للصف الأول الثانوي – الفصل الدراسي الأول. التصميم عربي من اليمين إلى اليسار، ويعمل على الكمبيوتر والتابلت والموبايل.

## محتويات النسخة

- 14 درسًا بالترتيب: 10 دروس في Unit 1: Aquatic Ecosystems و4 دروس في Unit 2: The Atmosphere.
- 183 قسم شرح يتضمن فقرات تفصيلية، أمثلة محلولة، معادلات، جداول مقارنة، ملاحظات وتصحيحات للمفاهيم الشائعة.
- 234 سؤال اختيار من متعدد مع تصحيح فوري وسبب الإجابة.
- 110 مصطلحات علمية إنجليزية وعربية قابلة للبحث والفتح من داخل الشرح.
- 25 محاكاة رقمية داخل الموقع؛ لا توجد تجارب منزلية مطلوب من الطالب تنفيذها.
- حفظ تقدم الدروس والثيم محليًا على نفس المتصفح باستخدام `localStorage`، دون حسابات أو إرسال بيانات إلى خادم.

## تصحيح مهم في درس توزيع المياه

- تغطي المياه نحو 71% من مساحة سطح الأرض.
- من إجمالي مياه الأرض: نحو 97.5% مياه مالحة و2.5% مياه عذبة.
- عند تفصيل المياه العذبة وحدها: نحو 68.7% منها جليد وأنهار جليدية، و30.1% مياه جوفية، ونحو 1.2% مياه سطحية ومخزونات أخرى.
- النسب 68.7% و30.1% و1.2% محسوبة من **المياه العذبة فقط**، وليست من إجمالي مياه الأرض. القيم تقريبية تعليمية.

## تشغيل الموقع محليًا

يمكن فتح `index.html` مباشرة في متصفح حديث. أو شغّل خادمًا محليًا من داخل مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر على Vercel

1. ارفع ملفات المجلد إلى مستودع GitHub.
2. في Vercel اختر **Add New → Project** ثم استورد المستودع.
3. اختر **Other** كـ Framework Preset.
4. اترك Build Command وInstall Command فارغين.
5. اجعل Output Directory هو `.` ثم اضغط **Deploy**.

المشروع Static ولا يحتاج إلى Backend أو قاعدة بيانات أو مفاتيح API أو تثبيت حزم.

## ملفات المشروع

- `index.html` — هيكل الموقع وواجهاته.
- `style.css` — تصميم الواجهة، الرسوم، الحركات، ودعم الشاشات المختلفة.
- `lessons.js` — الدروس، الشروحات، الأسئلة، والقاموس.
- `experiments.js` — بيانات 25 محاكاة رقمية.
- `app.js` — التنقل، عرض الشروحات، تشغيل المحاكاة، الاختبارات، والبحث وحفظ التقدم.
- `vercel.json` — إعدادات النشر الثابت.

## ملاحظات علمية

المحتوى مكتوب بصياغة تعليمية أصلية، وليس نسخًا حرفيًا من كتاب المعاصر أو كتاب الوزارة. ترتيب الوحدات والدروس يتبع فهرس منهج 2026–2027 الذي تمت مراجعته. الأرقام الطبيعية والحدود الجوية وبعض النماذج معروضة كقيم تقريبية، ويذكر الموقع ذلك في مواضعها. المحاكيات أدوات فهم بصري وليست بديلًا عن القياسات العلمية الحقيقية أو النماذج العددية المتخصصة.
